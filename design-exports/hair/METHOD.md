# Designing vector art in HTML/JS and converting it to a native Illustrator file

A complete account of the method, including the mistakes and the fixes, so it can
be reproduced or critiqued.

---

## 1. The format constraint that drives everything

A modern `.ai` file is **not** a bespoke format you can hand-author. Since
Illustrator 9, `.ai` is a **PDF container** (this one reports `%PDF-1.6`) that
additionally carries a private, compressed stream called `AIPrivateData` holding
the true native art — layers, live effects, editable text, appearance stacks.
The PDF half is what other apps read; the private half is what Illustrator reads.

That leaves three options, and only one is good:

| Approach | Result |
|---|---|
| Write a PDF, rename to `.ai` | Illustrator opens it, but as a **PDF import**: flattened, layer names lost, grouping mangled |
| Write legacy `.ai` (PostScript, Illustrator ≤8) | Still openable, but ancient; no gradients-as-gradients, no modern features |
| **Have Illustrator itself write the file** | A genuine native `.ai` with real layers |

Illustrator 30.6 was installed locally, so the third path was available: script
Illustrator to open an SVG and save it. **SVG is the bridge format** — Illustrator
imports it natively and preserves paths, gradients, groups, opacity, stroke
joins/caps, and live text (if the fonts are installed).

### What does NOT survive the crossing

This is the single most important design constraint. Anything that is a *CSS
effect* rather than *geometry* is lost:

- `box-shadow`, `text-shadow`
- `filter: blur()`, `backdrop-filter`
- CSS gradients on HTML elements, `border-radius` on divs
- blend modes and opacity-layered overlays (partially/unreliably)
- `@font-face` web fonts loaded by URL
- SVG `<filter>` primitives like `feGaussianBlur` (rasterized or dropped)

So "design in HTML" cannot mean "style divs." It must mean **emit geometry**. In
practice: author SVG inside the HTML page. SVG *is* HTML-renderable, so you get a
real browser design surface that converts losslessly.

Concretely: the glow behind the hair looks like a blur, but it is a **vector
radial gradient on an ellipse**, precisely so it survives. A `feGaussianBlur`
would have rasterized.

## 2. Architecture: one source of truth

The generator is a single file, `hair.js`, written as a classic script with a
UMD-style tail:

```js
(function (root) {
  /* ... */
  root.buildHairSVG = buildHairSVG;
  if (typeof module !== 'undefined' && module.exports) module.exports = { buildHairSVG };
})(typeof window !== 'undefined' ? window : globalThis);
```

This lets the **same code** run in two places:

- `index.html` loads it with `<script src="hair.js">` and injects the result into
  the DOM — the browser design surface.
- `export-svg.js` `require()`s it in Node and writes `hair.svg` to disk — the
  file Illustrator opens.

The preview and the export therefore cannot drift.

> **Gotcha:** do *not* use ES modules here. `import` from a `file://` page is
> blocked by CORS in Chrome, so the page silently fails. A classic
> `<script src>` works fine on `file://`.

## 3. The geometry engine

The art is not hand-drawn path data (mostly). It is generated by sweeping a
varying width along a bezier spine. Four layers of math:

### 3.1 Bezier evaluation and derivative

Standard cubic basis, plus the derivative for tangents:

```js
function cubic(p0, c1, c2, p3, t) {
  const m = 1 - t;
  const a = m*m*m, b = 3*m*m*t, c = 3*m*t*t, d = t*t*t;
  return [a*p0[0] + b*c1[0] + c*c2[0] + d*p3[0],
          a*p0[1] + b*c1[1] + c*c2[1] + d*p3[1]];
}

function cubicD(p0, c1, c2, p3, t) {   // first derivative
  const m = 1 - t;
  const a = 3*m*m, b = 6*m*t, c = 3*t*t;
  return [a*(c1[0]-p0[0]) + b*(c2[0]-c1[0]) + c*(p3[0]-c2[0]),
          a*(c1[1]-p0[1]) + b*(c2[1]-c1[1]) + c*(p3[1]-c2[1])];
}
```

### 3.2 Chained spines from a flat array

A spine is a flat array `[x0,y0, c1x,c1y, c2x,c2y, x1,y1, c3x,c3y, ...]`. Segments
are read with **stride 6**, so the endpoint of segment *N* is automatically the
start point of segment *N+1* — the chain is C0-continuous by construction:

```js
for (let i = 0; i + 8 <= pts.length; i += 6) { /* p0,c1,c2,p3 = pts[i..i+7] */ }
```

### 3.3 Sampling with normals

Walk each segment, and at every sample compute the **unit normal** by rotating
the tangent 90°: `n = (-dy, dx) / |d|`.

One real trap: when a control point coincides with its anchor, the derivative at
`t=0` is the zero vector and the normal becomes `NaN`, which poisons the whole
path. Guard by resampling slightly ahead:

```js
if (len < 1e-6) {
  d = cubicD(s[0], s[1], s[2], s[3], Math.min(0.999, t + 0.01));
  len = Math.hypot(d[0], d[1]) || 1;
}
```

### 3.4 The `lock()` primitive — a tapered hair strand

This is the workhorse. Offset the sampled spine by `±w` along the normal, where
`w` comes from a width array interpolated across the length. Concatenate the left
side with the **reversed** right side to close the loop:

```js
function lock(spine, ws, per) {
  const S = sampleChain(spine, per || 16);
  const L = [], R = [];
  for (let i = 0; i < S.length; i++) {
    const w = widthAt(ws, i / (S.length - 1));
    L.push([S[i].p[0] + S[i].n[0]*w, S[i].p[1] + S[i].n[1]*w]);
    R.push([S[i].p[0] - S[i].n[0]*w, S[i].p[1] - S[i].n[1]*w]);
  }
  return smoothClosed(L.concat(R.reverse()), 1);
}
```

A final width of `0` makes both sides converge to a single point — that is what
produces a natural pointed hair tip, for free.

### 3.5 Catmull-Rom → Bezier (why this step matters for Illustrator)

Sampling produces a dense polyline. Emitting it as `L` commands would hand
Illustrator hundreds of straight segments — technically correct, horrible to
edit, and visibly faceted. Instead convert the polyline back into **real cubic
curves** using the Catmull-Rom → Bezier identity:

```
c1 = p1 + (p2 - p0) / 6
c2 = p2 - (p3 - p1) / 6
```

```js
const c1 = [p1[0] + (p2[0]-p0[0])*k, p1[1] + (p2[1]-p0[1])*k];
const c2 = [p2[0] - (p3[0]-p1[0])*k, p2[1] - (p3[1]-p1[1])*k];
d += ` C ${c1} , ${c2} , ${p2}`;
```

The closed variant wraps indices modulo *n*; the open variant clamps at the ends.
A `dedupe()` pass first removes coincident points (within 0.4 units), because
duplicates produce zero-length tangents and cusps.

Result: smooth curves with a manageable number of editable anchors in Illustrator.

## 4. The iteration loop (the part that actually determines quality)

Headless Chrome renders the page at exact pixel size, with no browser extension
or GUI involved:

```bash
node export-svg.js
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
  --headless --disable-gpu --hide-scrollbars \
  --window-size=1100,1400 --screenshot=render.png \
  "file://$PWD/index.html"
```

Then **look at the PNG and critique it**. This ran six times. The art problems and
their fixes are the genuinely transferable knowledge:

| # | Symptom | Cause | Fix |
|---|---|---|---|
| 1 | Crown read as **banana segments** | Every lock had a heavy dark stroke | Only hero sections get real outlines; interior = flat tone + thin flow lines |
| 2 | Path artifact / hook inside the face opening | Hand-authored silhouette snaked back on itself | Rewrote the silhouette as a clean single traversal |
| 3 | Fringe read as **sawtooth teeth** | Fringe cut into the bang edge with straight `L` commands | Made each fringe tip a separate tapered `lock()` |
| 4 | Fringe locks read as **triangles** | Width tapered linearly to zero from the root | Hold width, then taper late: `[46, 44, 33, 0]` |
| 5 | **Shelves** across the tops of strands | Rounded root caps were visible | Draw order: fringe *before* bang, so the bang covers the roots; extend tress roots up under the bang and side cap |
| 6 | Bang **floated as a pale leaf** | Bang used the lightest gradient, breaking tonal unity | Fill it with the same gold as the silhouette; let highlights do the lifting |

### The silhouette is a horseshoe, not a donut

Worth stating explicitly because it is easy to get wrong: the reference hair is
**open at the bottom** between the two falls. So the outline is a single closed
path traversing: up the outer left edge → over the crown → down the outer right →
around the right tips → back up the inner right → across the fringe line → down
the inner left → around the left tips → close.

It is *not* a shape with an interior hole. Using an even-odd compound path would
have been wrong.

### Draw order is a design tool

Final stacking, bottom to top:

```
Backdrop → Silhouette → Crown Locks → Left Leg → Right Leg
        → Side Cap → Fringe → Bang Sweep → Flow Lines → Highlights
```

Putting `Fringe` *under* `Bang Sweep` is what hides every fringe root. This kind
of ordering does more for the result than any amount of curve tweaking.

## 5. Driving Illustrator (ExtendScript)

Illustrator is automated with **ExtendScript** (`.jsx`, an old ES3-era dialect —
no `let`, no arrow functions, no template literals). Invoke it from the shell via
AppleScript:

```bash
osascript -e 'tell application "Adobe Illustrator" to do javascript file "/abs/path/svg-to-ai.jsx"'
```

The script's return value comes back on **stdout**, which is how the run reported
its layer list back to the shell.

```jsx
#target illustrator

app.userInteractionLevel = UserInteractionLevel.DONTDISPLAYALERTS;  // critical

var doc = app.open(new File(dir + 'hair.svg'));

// Promote each top-level SVG group to its own named Illustrator layer.
var base = doc.layers[0];
var tops = [];
for (var i = 0; i < base.pageItems.length; i++) {
  var it = base.pageItems[i];
  if (it.parent === base && it.typename === 'GroupItem') tops.push(it);
}
for (var j = tops.length - 1; j >= 0; j--) {
  var L = doc.layers.add();
  L.name = tops[j].name || ('Group ' + (j + 1));
  tops[j].move(L, ElementPlacement.PLACEATBEGINNING);
}
if (base.pageItems.length === 0) base.remove();

var opts = new IllustratorSaveOptions();
opts.pdfCompatible = true;
doc.saveAs(new File(dir + 'hair.ai'), opts);
doc.close(SaveOptions.DONOTSAVECHANGES);
```

Key points:

- **`DONTDISPLAYALERTS` is not optional.** Any modal dialog blocks the script and
  hangs the automation with no error.
- **SVG `id` becomes the Illustrator group name.** That is the entire mechanism
  by which `<g id="Bang Sweep">` ends up as a layer called `Bang Sweep`. Name
  your groups deliberately.
- Filter `it.parent === base`, because `base.pageItems` also reports nested items.
- Iterate **in reverse** so `doc.layers.add()` (which inserts at the top) yields
  the original stacking order.
- **Do not set `artboardRect = doc.visibleBounds`.** This was a real bug in the
  first run: the glow ellipse deliberately overspills the canvas, so fitting to
  visible bounds produced an oversized artboard with dead margin. Illustrator
  already creates a correct artboard from the SVG `viewBox` — leave it alone.

## 6. Verification — do not assume it worked

Four independent checks, because "Illustrator didn't error" proves nothing:

**Is it actually native, or just a renamed PDF?**
```bash
strings hair.ai | grep -oiE "AIPrivateData|AIMetaData" | sort | uniq -c
#   1 AIMetaData
#   2 AIPrivateData
```

**Did the layer names reach the native stream?**
```bash
strings hair.ai | grep -oE "Bang Sweep|Fringe|Silhouette|Highlights|Flow Lines"
```

**Does the artwork actually survive?** Rasterize the saved `.ai` via its PDF half
and look at it — this catches silent geometry loss that metadata checks miss:
```bash
gs -dNOPAUSE -dBATCH -sDEVICE=png16m -r72 -dUseCropBox -sOutputFile=verify.png hair.ai
```

**Is the artboard right?**
```bash
grep -a -o '/MediaBox[^]]*]' hair.ai     # → /MediaBox [0.0 0.0 1100.0 1400.0]
```

## 7. Text, if the artwork has any

This piece is pure paths, but for anything with type:

- Illustrator resolves live text only against **system-installed** fonts. A
  `@font-face` file referenced by the web page is invisible to it. Install the
  `.ttf`/`.otf` into `~/Library/Fonts/` first, or the text opens as a missing font.
- The alternative is outlining every glyph to paths: renders identically
  anywhere with zero font dependency, but the text is no longer editable.
- Match the SVG `font-family` to the font's real family name, not the CSS alias.

## 8. Reproducing it

```bash
node export-svg.js        # regenerate hair.svg / hair-no-bg.svg
osascript -e 'tell application "Adobe Illustrator" to do javascript file "…/svg-to-ai.jsx"'
```

Because the art is parametric, editing the spine arrays changes the design
without touching any path data — e.g. the `LEFT_TRESS` / `RIGHT_TRESS` spines
control hair length, and the width arrays control taper.

---

## 9. Honest assessment of the output

The result is recognizably the target style but looser than the reference:
the crown's bang sweep reads as one leaf-shaped mass rather than layered
overlapping sections, the falls read as somewhat parallel tresses instead of
interleaving, and there is less tonal depth between strands than the source has.
Six iterations got it to "clearly the same style," not to "indistinguishable."
